# SH0 측정 기록지 — C1 수락 (U1~U3)

기준: [방향 brief](./specs/instruction-centric-direction-brief.md) §6, [C1 brief](./specs/c1-session-hub-chat-brief.md) §7. 측정은 사용자가 직접 한다. U1~U3 는 **C1 수락 판정**이며, 미달이어도 SH1 진입을 막지 않는다(§0.2.10). 미달 원인은 C1 보완 큐로 간다.

## 공통 규칙

- 결과는 **정답 / 오답(오귀속 포함) / 불명 / 자료 부족** 넷으로 나눈다. 분모는 전체 표본이다.
- 최소 표본(U1 10 · U2 5 · U3 5)보다 적으면 기록은 하되 통과 판정하지 않는다.
- 시간에는 질문 입력·추가 질문·칩 클릭을 모두 넣는다.
- 기존 방식(터미널·Orca 직접 확인)과 비교할 때는 표본을 다르게 하거나 순서를 바꾼다.
